# ChatGPT-Style App

Simple Node.js + Express + OpenAI chat app with a web UI.

## Setup

1. Install dependencies:
   - `npm install`
2. Create environment file:
   - Rename `.env.example` to `.env`
   - Add your `OPENAI_API_KEY`
3. Start app:
   - `npm start`
4. Open:
   - `http://localhost:3000`
# ChatGPT-Style App

Simple Node.js + Express + OpenAI chat app with a web UI.

## Setup

1. Install dependencies:
   - `npm install`
2. Create environment file:
   - Copy `.env.example` to `.env`
   - Add your `OPENAI_API_KEY`
3. Start app:
   - `npm start`
4. Open:
   - `http://localhost:3000`

## Notes

- Chat history is kept in browser memory for the current tab session.
- For production, add authentication, rate limiting, and persistent storage.
